# Mythøs Network — Discord Bot (`expo_DC`)

Bot oficial do Discord da Mythøs Network.

## Sistemas
- Slash commands
- Tickets privados
- Moderação e logs
- Advertências persistentes
- Whitelist com cargo automático
- Consulta UDP real do servidor SA-MP/Open.MP
- Status Mythøs Network | NYX Roleplay

## Instalação
```bash
npm install
cp .env.example .env
npm run build
npm start
```

Configure o `.env` com token, client ID, guild ID, cargos/canais e IP/porta do servidor.

**Nunca publique `DISCORD_TOKEN`.**
