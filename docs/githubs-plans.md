# Planos do GitHub

Este documento resume e adapta as opções de planos do GitHub para facilitar a escolha dentro deste projeto. Não é uma cópia literal da documentação oficial; é uma versão condensada e organizada para uso local.

## Visão geral
O GitHub oferece vários planos para diferentes necessidades — desde uso individual e projetos de código aberto até equipes e empresas que precisam de funcionalidades avançadas de segurança, gestão e suporte.

Os pontos principais a comparar entre planos incluem:
- Repositórios públicos e privados: número de colaboradores e limites por plano.
- Ações (GitHub Actions): minutos de CI/CD e limites de uso.
- Codespaces e GitHub Pages: disponibilidade e cotas.
- Segurança e conformidade: análise de código, dependabot, SAML/SSO, logs de auditoria.
- Suporte e faturamento: nível de suporte e opções de faturamento empresarial.

## Planos comuns

### Plano Free
- Ideal para indivíduos e projetos open source.
- Repositórios públicos e privados ilimitados.
- GitHub Actions com cotas gratuitas limitadas.
- Acesso a Issues, Pull Requests, Pages e Packages em nível básico.

### Plano Team / Pro
- Recomendado para equipes pequenas e desenvolvedores profissionais.
- Funcionalidades colaborativas adicionais (permissões refinadas, revisão de código avançada).
- Mais minutos de Actions e limites maiores para Packages/Codespaces dependendo do plano pago.

### GitHub Enterprise (Cloud e Server)
- Para organizações que precisam de controle, conformidade e integrações corporativas.
- SAML/SSO, provisionamento automático, logs de auditoria e políticas de segurança centralizadas.
- Suporte empresarial e opções de faturamento por contrato.
- Disponível como Enterprise Cloud (hospedado pelo GitHub) e Enterprise Server (hospedado pelo cliente).

## Segurança e automação
Recursos como GitHub Advanced Security (análise de código estático, secret scanning, dependabot) podem estar disponíveis apenas em planos pagos. Esses recursos ajudam a identificar vulnerabilidades e a automatizar correções.

## Como escolher
1. Avalie o tamanho da equipa e a necessidade de colaboração.
2. Verifique se precisa de funcionalidades de compliance (SSO, políticas, auditoria).
3. Avalie o uso estimado de CI (Actions) e Codespaces para calcular custos.
4. Para empresas, consulte o plano Enterprise para opções de suporte e contrato.

## Atualizar ou mudar de plano
- A gestão de planos e faturamento é feita no painel da organização/conta no GitHub (Settings → Billing).  
- Para migração a Enterprise Server, planeje a infraestrutura e a migração dos dados.

## Perguntas frequentes rápidas
- Posso hospedar projetos privados no plano gratuito? Sim — repositórios privados ilimitados estão disponíveis no plano gratuito com limitações em cotas de Actions/Codespaces.
- O que é o Enterprise Cloud? É a oferta gerida pelo GitHub para organizações com recursos empresariais avançados.
